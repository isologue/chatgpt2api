## 已修复的问题

- 原 Condition 唤醒仅通知等待者，未预留名额。已复现新到请求抢在已有等待者之前；改为 FIFO Future 队列，在释放时同步交接名额。等待取消、交接后取消和总预算到期都回收名额，调低并发不取消在途下载。
- 原下载名额直到 response.close 才释放，包含后续图片校验及校验线程等待。现在 EOF 已等待底层流完成后便释放；响应清理和传输诊断继续正常执行。
- 增加循环私有正文读取字节计数，每 0.5 秒发布一次，保留 5 分钟有界历史。此速率表示应用消费正文，不冒充物理网卡带宽。失败尝试读取的字节也计入。
- 监控增加正文速率、下载名额占用、服务网络收发，以及慢回调的阶段、时间和线程 CPU 耗时。慢回调每周期最多 8 条；不记录账号、认证、URL、正文或连接地址。
- 慢回调显式区分生成流和元数据，并在响应开始读取时更新实际阶段，避免把整个 SSE 传输误归为提交请求。
